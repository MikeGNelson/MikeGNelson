# Michael Nelson

**Computer Graphics · XR · Computer Vision · Machine Learning**

I'm a simulation engineer and researcher working in computer graphics, extended reality, computer vision, and machine learning. My research focuses on novel locomotion and interaction techniques for immersive virtual environments.

## Research & Projects

### Graphics & Computer Vision
**3D Reconstruction**  
Browser-based two-view reconstruction pipeline using OpenCV.js, Three.js, and WebGPU, including feature matching, epipolar geometry, pose recovery, triangulation, dense stereo, and mesh reconstruction.  
[View Demo](https://michaelnelson.me/#graphics/reconstruction)

**Gaussian Splat Viewer**  
Interactive browser-based viewer for Gaussian splat reconstruction data using Three.js.  
[View Demo](https://michaelnelson.me/#graphics/gaussian)

**WebGPU Physarum Simulation**  
GPU-based agent simulation implemented with WebGPU and WGSL compute shaders.  
[View Demo](https://michaelnelson.me/#graphics/physarum)

**Rendering Lab**  
Interactive real-time rendering experiments and graphics techniques.  
[View Demo](https://michaelnelson.me/#graphics/rendering)

**Deformable Snow**

[View Demo](https://michaelnelson.me/#graphics/snow)

## Research

My doctoral research investigates **center of balance as an input modality for virtual reality locomotion**, including balance-based controllers, locomotion mappings, terrain traversal, presence, workload, and cybersickness.

My work has appeared at **IEEE ISMAR** and **IEEE VR**.
